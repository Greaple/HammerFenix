Quelques conseils rapides

Si vous rencontrez un problème avec le jeu (s'il ne fonctionne pas ou vous ne le voyez pas correctement), vous pouvez essayer l'un des points suivants :

  1. Pensez à mettre une résolution d'écran de 1024x768px minimum
  2. Videz votre cache Internet
  3. Installez la dernière version du lecteur Flash
  4. Installez le navigateur Firefox

L'écran de jeu est trop grande...

Pensez à mettre une résolution d'écran de 1024x768px minimum. Ça peut vous paraître petit au début, mais vous vous habituerez. La plupart des gens utilisent cette résolution d'écran.

Sur Windows :

  • faites clic droit de souris sur le bureau de Windows (où il y a les icônes)
  • cliquez sur "Propriétés"
  • Paramètres
  • Dans la partie Résolution de l'écran, faites glisser le bouton vers la droite pour avoir 1024*768.

Videz votre cache internet

Avant toute autre chose, pensez à essayer de vider le cache de votre navigateur Internet ! Cette opération simple peut solutionner bon nombre de problèmes techniques.

Sur Internet Explorer :

  • menu "Outils" en haut puis choisissez "Options Internet"
  • cliquez sur "Supprimer les Fichiers"
  • validez, fermez Internet Explorer et relancez le site

Sur Firefox:

  • menu "Outils", choisissez "Options"
  • icône "Vie privée"
  • section "cache", choisissez "Videz le cache"
